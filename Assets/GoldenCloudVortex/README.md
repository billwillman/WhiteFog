# 金色滚动云洞

打开 [GoldenCloudVortex.unity](GoldenCloudVortex.unity) 并进入 Play。金白色洞口悬在远处；看左侧的灰蓝云影和相邻的亮边，可以看到两者一起翻卷、向近处掠过。微信开发者工具选择「小游戏」并导入 [WeChatMiniGame](WeChatMiniGame/)。

## 云壁如何连续移动

网格提供云壁的深度。材质根据深度和时间确定前后两个虚拟云段的采样位置，分别沿顺时针弧线移动原画，同时改变投影比例，让近处的云比远处移得快。两段在交界处平滑混合，一段淡出后从远处接回。每对云段对应 32 个场景深度单位，两组采样错开半个周期；基础云纹每 6.4 秒循环。云层亮边和灰蓝色阴影一起参与采样，暗部会跟着那片云移动。

镜头固定，洞心的位移权重为零，因此时间推进时，亮口的距离、轮廓和大小固定。云壁与洞口在材质中分别调色，让暖金色周围的暗云持续可见。

每 3.2 秒在云壁局部触发一次雷光。程序选取位置和强度，材质按距离、云面起伏方向与自制 MatCap 计算紫色透光。场景使用 Unlit 着色器，云壁明暗与雷光均由材质绘制。场景组件的 Flash Strength 可设为 0，便于单独观察云影和亮口。

## 性能参数

| 项目 | 最终版本 |
| --- | --- |
| 实际网格 | 1,729 个顶点，3,384 个三角形，10,152 个 16 位索引 |
| 云洞绘制 | 1 个子网格、1 个材质、1 个 Pass，每帧 1 次绘制 |
| 纹理 | 云彩图 1536×864，流向与 MatCap 合图 256×144，均使用双线性过滤 |
| 每片元纹理采样 | 平时 3 次，雷暴激活时 4 次。顶点阶段 0 次 |
| 小游戏缓冲 | 顶点与索引约 94.1 KiB。两张纹理按 RGBA8 上传、单级存储合计约 5.20 MiB，不含画布和驱动开销 |
| 微信小游戏渲染配置 | 目标 30 FPS，横屏上限 960×540，关闭 MSAA。特效采用网格和贴图流动，全程无 Ray Marching |

### 桌面实测

测试设备为 NVIDIA GeForce RTX 3080。预热后采样，P95 表示 95% 的样本耗时不超过该值。

| 环境及测量范围 | 分辨率 | 样本 | 中位数 | P95 |
| --- | --- | ---: | ---: | ---: |
| 团结编辑器 D3D11，离屏相机渲染并同步回读 1 像素 | 1280×720 | 180 | 0.57 ms | 2.60 ms |
| 桌面 Chrome WebGL 2，GPU 计时查询，仅云洞绘制，雷暴关闭 | 960×540 | 160 | 0.015 ms | 0.017 ms |
| 桌面 Chrome WebGL 2，GPU 计时查询，仅云洞绘制，雷暴点亮 | 960×540 | 160 | 0.017 ms | 0.019 ms |

编辑器与浏览器测量的范围不同。已验证桌面 WebGL 1 和 2 运行入口。微信手机上的持续帧率、功耗与温升尚待真机测量。
