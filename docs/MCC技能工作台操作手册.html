首次打开和试放

  1. 打开 E:\Tuanjie19_WhiteFog，等待团结完成脚本编译和资源导入。从菜单打开 Window → Soft Kitty → 技能工作台。已经在 Project 中选中技能图时，也可以点 Inspector 里的打开技能工作台。
  2. 点技能库，按名字或编号搜索 25090 破空剑法。
  3. 在动作时间轴检查 0 秒的动作和武器，以及 1.120、1.251、1.443 秒的三次飞剑发射。
  4. 切到 Preview → 快速试放。使用默认的 8 米距离，点打开角色预览并试放。
  5. 「每段预览来伤」是本地试放输入，默认 10。每把飞剑抵达才结算，头顶数字显示实际扣血。改成 0 可单看动作和特效。
  6. Play 中可直接切到另一张图，点再次试放所选技能。要保存新的设计参数，先退出 Play，再改图、保存并重试。

角色预览使用《宗师之上》男角色 001 与小雕。点「退出角色预览」回到之前的编辑场景。要用 Hierarchy 里的具体角色，请切换「当前场景试放」。

从技能引用 Buff，查看它的数值来源

  1. 在技能编辑页选择或复制一张技能图。在Buff 状态页展开「从 Buff 模板新建」，选择持续治疗，填入唯一 UID（例如 practice_regen）和显示名。创建后，该状态引用一张可以用 MCC 节点画布打开的效果图。
  2. 设持续 5 秒、可叠层、上限 2，勾选重复施加时补回时长和允许驱散。把 heal 改为 6 并保存状态库。Layer 来自运行中的实际层数。在预览场景默认的公共节拍上，一层每跳回复 6，两层每跳回复 12，最多回到有效最大生命。
  3. 在「挂到技能根节点」选受术者、开始秒数及「施加状态」，点「在游标处添加动作，返回技能页」。动作里能按显示名和 UID 更换状态，也能跳回定义。用两个新的练习技能分别引用相同状态，操作选「驱散一层」和「强制移除全部层」，即可分开试验。该按钮接到根节点；需要命中才挂状态时，请在节点画布把动作接到对应成功出口。
  4. 在状态定义点「查看公式与数值」，选择最后一个最小值节点。逐层展开的输入来自目标当前生命、最大生命、状态参数和层数。改变「试算输入」只影响预览；编辑「图内默认值」会修改该图，点「保存图资产」落盘。若多个状态共用效果图，仅调整某一状态的倍率可直接改该状态参数。需要改一套独立连线时，先点「复制成此状态的专用图」。
  5. 切到 Preview → 快速试放。观察「施放者状态」「目标状态」里的 UID、层数与剩余时间，配合当前生命核对每跳。再次施加可验叠层和刷新；换练习技能可验驱散与移除。做回复实验时，先让受术者损失部分生命。

按目标条件修改施法者

「新建技能 → 目标有状态时按攻击自疗」会按你选择的状态建立一张原生图。它从《宗师之上》流风回雪扇抽取一条制作路径：条件节点检查目标身上的状态，公式从施法者读取 atk，最后写回施法者的 chp。默认治疗倍率为 1.2，可以在公式页编辑。这个模板可用于主角或怪物。要实现原武学同时满足两项条件时的双份回复，需要另接第二条条件路径。

「吸收护盾」模板入口打开 MCC 高级伤害图，可检查能量盾的扣减过程。公式结算动作支持独立等级表和跨图公式引用。多盾优先级和按护盾实例驱散的规则仍待确定。技能平台设计与 MCC 边界

时间轴和节点怎么读

检查技能入口条件→安排动作→到执行时检查该动作的条件→执行通过的动作

例：第三剑要求目标正在灼烧。把三次出剑各做成一个发射动作，仅在第三次出剑的「动作前置条件」里添加持续状态判断，实体选「本次目标」，状态 UID 填状态库中的灼烧 UID（例如 burn），比较方式选存在。第二剑点燃目标且第三剑出手时灼烧仍在，第三剑才飞；出手前已驱散则跳过。剑离手后的抵达、命中和扣血由这把剑的技能逻辑决定。若需分别判断三次出剑，应把条件放在三次独立发射上。一个动作内部生成的弹丸或内部伤害段不会各自触发动作前置条件。

实体 A、B 怎么选。新建角度、距离或标签比较时，A 默认是施法者，B 是本次目标。怪物出招时施法者就是怪物。要限定友方，可在入口或该动作的条件菜单选「目标阵营 → 与施法者同阵营（比较标签）」，并指定双方存放阵营的标签序号。该条件筛选当前目标；需要从多名友军中挑选对象时应由选目标逻辑提供具体实体。「高级：全局玩家」固定读取全局玩家，「高级：技能执行实例」读取执行组件代表的位置、朝向等。旧图保留原绑定。

每行动作的开始时间以本次施放为零点。同一根节点可启动多行动作。要让第二步等到第一步完成，应填写合适的开始时间。飞行时间随距离变化。《破空剑法》在起手后分三次发射，飞剑的抵达时刻由发射距离、初速和加速度共同决定。

时间游标、横条与执行方式

点左侧动作名称，游标会对齐其开始时间。点右侧轨道，会选中该行并把游标放到点击位置。游标决定下一次「添加动作」的起点。移动已有动作时，选中它，在下方改「开始时间（秒）」并按回车。

「单次」执行一遍。「执行多次」填写次数和间隔，例如三段、间隔 0.14 秒，第一段到第三段相隔 0.28 秒。「持续执行」填写持续时间和执行间隔。行名末尾的「直接」表示连接根节点，「分支」表示经其他节点接入，「未连接」时应在节点图检查动作的执行输入。

动作类型

  • 施法提示指定提示对象、事件名、显示时长及施法或敌对预警类型。事件会发给所连实体。敌方预警可发给受术者，起手提示可发给施放者。
  • 分段命中与公式结算接施加者、目标和技能等级。点动作可配置等级表、三个公式引用和各段占比。节点画布上的按钮可直接打开三个公式树。
  • 旧动作技能命中接三个输入：施加者、受术者和伤害输入（点）。最后一个端口读入上游已经算好的点数。选飞剑、光弹或毒雾时，飞行时长取出发距离除以速度，弧线高度控制轨迹。射程填 0 表示不限；超距会中止此次动作并可显示提示。
  • 护盾与回复选择作用实体、效果类型和数值。护盾可设持续时间，回复以该实体的 hp 为上限，写入 chp。

「技能命中」勾选到达时施加易伤后可编辑百分比和时长。命中后到首段的延迟用于把减益与第一段伤害分开。工作台时间轴横条表示动作的计划重复区间，投射物的在途时间根据实战距离另算。

从空白制作一招公式飞剑

  1. 新建空白技能，加「实体存在判断」，让条件检查目标。时间轴添加「分段命中与公式结算」，将施加者接 Dealer、受术者接 Target。技能等级端口使用动态变量 skill.level，默认 1；正式调用方可在施放前用 CombatDamage.SetDynamicValue("skill.level", 等级) 传入该角色掌握的技能等级。
  2. 设置 0.30 秒开始、飞剑、射程 12 米、速度 20 米/秒。在动作上绑定「通用总伤害」「通用命中率」「通用防御结算」。在「技能等级表」选择自己的资产。选择自建等级表后，确认动作引用正确。
  3. 在技能摘要下方的技能等级表逐行编辑。攻击倍率填 0.55 表示最终攻击的 55%；固定加值填点数；基础命中率填 95 表示 95%；身法修正填 0.5 表示双方每相差 1 点身法，命中率变化 0.5 个百分点。点「新增一级」会复制当前最高等级的数值，新行可以单独修改。顶部「保存」同时保存技能图与绑定的等级表。若多个技能引用同一张表，保存的改动对这些技能都生效。
  4. 单段填写 100。三段时选「执行多次」，次数 3，点「按当前 3 段均分 100%」生成三栏，再分别填 20、30、50。段数与占比数量必须一致，合计 100%。每段只处理自己的份额，落空的份额直接结束。
  5. 在公式结算动作里选「公式试算等级」，再点「看公式」，即可使用这一级的表行试算，并调整模拟属性。Preview 的「试放技能等级」单独选择。用「用原生节点树编辑连线」改公式；若只想改这一招，先在该槽点「专用副本」。改了输出节点时，在公式页选新节点，再点「把当前节点设为运行时输出」并保存。
施放：最终攻击 × 等级倍率 + 固定项→抵达：本段独立判命中→成功：分段伤害减去本段分摊的实时防御→易伤、护盾、剩余生命

例如总伤害 200，三段占 20%、30%、50%，各分得 40、60、100。若目标当前防御 50，三段均命中且没有护盾或易伤，则实际扣 30、45、75。第二段落空时它扣 0，第三段仍只占原定的 50%。防御在段与段之间改变时，后续命中使用新值。

本地预览将来伤送入角色生命和护盾结算。原作按战报确定各段伤害与目标；四招试放中的飘字用于核对触发和目标，原服伤害数值及多人分摊仍需战报核实。

对照实机看四个时刻

看玩家测试视频约 3.1 到 4.6 秒：先看下方角色起手，再看前方两路剑光和敌人身上的亮闪。作者将破空剑法排在第一位，后面还接有其他武学。本工作台的八米试放只绑定一只小雕，三次发射会走同一路线。玩家实录：「六武当」正文中「以下是测试视频」后的短片。

技能表 25090 指定动作、出剑时间与技能特效。坐骑外观随角色装备，此预览选用原包一级 lys 飞剑。原挂件在这一层级没有骑乘挂点，工作台以剑刃上表面对齐脚下。待机和施法时，坐骑剑尖朝向前方的小雕，剑柄在主角身后。角色用一个原动画采样帧衔接起手。桌面材质读取粒子 UV、逐粒子溶解和原材质队列。高光映射使用原包 ACES0 曲线，泛光按高画质默认配置（阈值 0.9、强度 0.6、散射 0.7）适配。

核对伤害飘字

以 8 米试放。飞剑在途中，目标生命保持原值；抵达后，头顶飘字显示生命变化。试放前记录目标生命，结束后对照「目标生命」的前后读数。若每剑输入 10，目标生命充足且没有护盾、易伤，三剑合计扣 30。每剑来伤设为 0，或护盾完全吸收时，生命维持原值。

打断施法与飞剑离手

在 Preview 试放后点「打断施放者」。打断会结束本次施法的剩余时间轴。尚未触发的施法提示、特效、加状态、回复、直接攻击段和投射发射都取消。例如两次发射分别安排在 0.40 秒和 0.72 秒，若在 0.55 秒打断，第一把飞剑继续飞向目标并按原配置判定命中，第二把取消。一次投射后的多段判定仍属于同一个已发出的效果。需要两次独立出剑时，在时间轴配置两个发射动作。

控制技能可在「添加动作 → 打断施法」里选择接收事件的角色，默认是目标。角色控制器和动画事件也可调用 EntityComponent.InterruptCast()。「变换 → 移动」和「传送」动作可勾选「位移时打断受术者施法」；受术者产生位移时触发一次。「Buff 状态」定义可勾选「进入状态时打断施法」；首次施加或移除后再进入会触发，刷新、叠层和周期结算不会重复打断。两种来源调用同一个入口。若震退已经通过踉跄状态触发打断，仅在该状态配置即可。普通扣血与施法打断独立。打断后重新施法可以正常出剑。

试放自己指定的角色、执行器或武器

  1. 在要验收的场景选 Preview → 当前场景试放，进入 Play。把要出招的实例拖入「施加者」，把要受击的实例拖入「目标」。已有有效的 EntityComponent 即可，执行组件可留空。
  2. 如要验收武器上现成的 CombatDamage，可用「查找使用此图的场景组件」绑定它，再展开「命中检测、投射物与动态变量」。
  3. 选择试放技能等级，点试放当前技能。预览镜头对准所选对象，结果显示双方名称和实体 UID。手动试放通过指定目标调用图。要测试碰撞层、射线或实际命中体，请另用武器或角色的正常施法入口触发物理检测。

MCC 原版多个延迟动作复用同一个执行器时可能串目标。快速试放为每次施放分配独立实例。接入正式角色时，并行施放也应保留独立的执行上下文和足够的存活时间。

核对护盾和生命

在「当前场景试放」选择带护盾的受术者，按受击前后的盾量和生命核对。来伤超过剩余护盾时，头顶数字等于实际生命损失。生命不足一段伤害时，扣血以当前剩余生命为限。

常见问题

技能库找不到某张图

点顶部「技能库」，清空「查找技能」。原作列表按技能 ID 排序。要编辑个人草稿，请从 Project 拖入资产槽。

当前画面还是 DemoScene 或其他游戏场景

要试放男角色 001 和小雕，先退出当前 Play，再点「打开角色预览并试放」。要使用正在运行的场景实例，直接选「当前场景试放」并指定双方。如果 Play 已暂停，先恢复播放。

能看到特效，但伤害看起来偏少或偏多

先查射程、技能等级表、各段占比、命中率、目标防御与当前生命，再查护盾或易伤，再确认次数、间隔与在途时间。血量不足时结算会受剩余生命限制。快速试放保留本轮双方生命、护盾和状态。要恢复初始条件，退出角色预览再进入。

编辑框变灰，或节点图和工作台显示不同

先退出 Play。若节点图正在编辑同一资产，点「切回工作台编辑」。确认正在编辑原图还是副本，用路径核对同名技能。输入框按回车后再保存。

Console 出现找不到 SkillPlayback 或自定义动作

检查 Assets/SoftKitty/MasterCombatCore/Scripts/Core/SkillPlayback.cs、动作脚本及其 _interface.txt 是否已导入。等待脚本编译结束，从 Console 第一条红色错误开始排查。运行时反射类型同时在插件 link.xml 中登记。

如何查看更复杂的条件和公式

选中图后点「打开节点图」，从根节点的触发输入和动作输出追查连线。工作台中显示「来自节点」的端口说明它连接了公式或分支。原图使用方法见团结技能节点编辑器手册。
