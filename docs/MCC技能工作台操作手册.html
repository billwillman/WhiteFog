首次打开和试放

  1. 打开 E:\Tuanjie19_WhiteFog，等待团结完成脚本编译和资源导入。从菜单打开 Window → Soft Kitty → 技能工作台。已经在 Project 中选中技能图时，也可以点 Inspector 里的打开技能工作台。
  2. 首次打开时可直接看到技能库。如果窗口已有选中的技能，点顶部技能库打开列表。在「主角技能」里点御剑穿云。搜索框按技能名称筛选，清空即可恢复全部。点选后，窗口上方显示当前图的名字和摘要。
  3. 技能摘要下方直接显示技能等级表，每一级占一行。例如御剑穿云 2 级的攻击倍率为 0.66、基础命中率为 95（95%）。在格内输入数值，点顶部保存。在动作时间轴选分段命中与公式结算可查看三张公式图与各段占比。御剑穿云在 0.24 秒检查 16 米射程，飞剑速度 19 米/秒，第 1 段占比 100%。
  4. 切到顶部 Preview 页签，选择快速试放。当前技能仍为御剑穿云，「本次施放方向」默认使用「主角 → 怪物」。勾选让怪物就位到主角前方，将起始距离设为 8 米。
  5. 点打开 Preview 场景并试放。如团结询问是否保存原场景，按项目需要保存后继续。编辑器会打开 MCC 原版 URP 预览场景，进入 Play，等待主角与可交互的敌人生成，再施放所选技能。
  6. 先设「试放技能等级」为 1，在 8 米处试放。约 0.66 秒是预计抵达时刻，每段到时独立判命中。记录目标生命差，再换成等级 3 复测。血量差受防御、易伤和护盾影响，屏幕上的「命中」也可能对应零扣血。
  7. Play 中可直接切到另一张图，点在 Preview 中试放所选技能。要保存新的设计参数，先退出 Play，再改图、保存并重试。

快速试放会自动绑定预览场景中存活的主角和最近一只可交互怪物。第一次试放不需要手动建执行物体，也不需要把九张图分别挂到场景。

从技能引用 Buff，查看它的数值来源

  1. 在技能编辑页选择或复制一张技能图。在Buff 状态页展开「从 Buff 模板新建」，选择持续治疗，填入唯一 UID（例如 practice_regen）和显示名。创建后，该状态引用一张可以用 MCC 节点画布打开的效果图。
  2. 设持续 5 秒、可叠层、上限 2，勾选重复施加时补回时长和允许驱散。把 heal 改为 6 并保存状态库。Layer 来自运行中的实际层数。在预览场景默认的公共节拍上，一层每跳回复 6，两层每跳回复 12，最多回到有效最大生命。
  3. 在「挂到技能根节点」选受术者、开始秒数及「施加状态」，点「在游标处添加动作，返回技能页」。动作里能按显示名和 UID 更换状态，也能跳回定义。用两个新的练习技能分别引用相同状态，操作选「驱散一层」和「强制移除全部层」，即可分开试验。该按钮接到根节点；需要命中才挂状态时，请在节点画布把动作接到对应成功出口。
  4. 在状态定义点「查看公式与数值」，选择最后一个最小值节点。逐层展开的输入来自目标当前生命、最大生命、状态参数和层数。改变「试算输入」只影响预览；编辑「图内默认值」会修改该图，点「保存图资产」落盘。若多个状态共用效果图，仅调整某一状态的倍率可直接改该状态参数。需要改一套独立连线时，先点「复制成此状态的专用图」。
  5. 切到 Preview → 快速试放。观察「施放者状态」「目标状态」里的 UID、层数与剩余时间，配合当前生命核对每跳。再次施加可验叠层和刷新；换练习技能可验驱散与移除。做回复实验时，先让受术者损失部分生命。

按目标条件修改施法者

「新建技能 → 目标有状态时按攻击自疗」会按你选择的状态建立一张原生图。它从《宗师之上》流风回雪扇抽取一条制作路径：条件节点检查目标身上的状态，公式从施法者读取 atk，最后写回施法者的 chp。默认治疗倍率为 1.2，可以在公式页编辑。这个模板可用于主角或怪物。要实现原武学同时满足两项条件时的双份回复，需要另接第二条条件路径。

「吸收护盾」模板入口打开 MCC 高级伤害图，可检查能量盾的扣减过程。八招已经支持独立等级表和跨图公式引用。多盾优先级和按护盾实例驱散的规则仍待确定。技能平台设计与 MCC 边界

时间轴和节点怎么读

检查施放条件→战斗根节点→按各动作的开始时间执行→表现和数值结算

每行动作的开始时间以本次施放为零点。同一根节点可启动多行动作。要让第二步等到第一步完成，应填写合适的开始时间。飞行时间随距离变化。八招把判定接在抵达之后；缚影蚀脉在首段命中后先挂易伤，再等待配置的延迟才算防御。

时间游标、横条与执行方式

点左侧动作名称，游标会对齐其开始时间。点右侧轨道，会选中该行并把游标放到点击位置。游标决定下一次「添加动作」的起点。移动已有动作时，选中它，在下方改「开始时间（秒）」并按回车。

「单次」执行一遍。「执行多次」填写次数和间隔，例如三段、间隔 0.14 秒，第一段到第三段相隔 0.28 秒。「持续执行」填写持续时间和执行间隔。行名末尾的「直接」表示连接根节点，「分支」表示经其他节点接入，「未连接」时应在节点图检查动作的执行输入。

动作类型

  • 施法提示指定提示对象、事件名、显示时长及施法或敌对预警类型。事件会发给所连实体。比如雷鳞震翅把预警放在受术者，御剑穿云把起剑提示放在施加者。
  • 分段命中与公式结算接施加者、目标和技能等级。点动作可配置等级表、三个公式引用和各段占比。节点画布上的按钮可直接打开三个公式树。
  • 旧动作技能命中接三个输入：施加者、受术者和伤害输入（点）。最后一个端口读入上游已经算好的点数。选飞剑、光弹或毒雾时，飞行时长取出发距离除以速度，弧线高度控制轨迹。射程填 0 表示不限；超距会中止此次动作并可显示提示。
  • 护盾与回复选择作用实体、效果类型和数值。护盾可设持续时间，回复以该实体的 hp 为上限，写入 chp。清罡护体的两行动作都接「施加者」。

「技能命中」勾选到达时施加易伤后可编辑百分比和时长。命中后到首段的延迟用于把减益与第一段伤害分开。工作台时间轴横条表示动作的计划重复区间，投射物的在途时间根据实战距离另算。

从空白制作一招公式飞剑

  1. 新建空白技能，加「实体存在判断」，让条件检查目标。时间轴添加「分段命中与公式结算」，将施加者接 Dealer、受术者接 Target。技能等级端口使用动态变量 skill.level，默认 1；正式调用方可在施放前用 CombatDamage.SetDynamicValue("skill.level", 等级) 传入该角色掌握的技能等级。
  2. 设置 0.30 秒开始、飞剑、射程 12 米、速度 20 米/秒。在动作上绑定「通用总伤害」「通用命中率」「通用防御结算」。在「技能等级表」选择自己的资产。可在 Project 复制「御剑穿云」等级表后改值；检查复制出的表已绑定到当前动作。
  3. 在技能摘要下方的技能等级表逐行编辑。攻击倍率填 0.55 表示最终攻击的 55%；固定加值填点数；基础命中率填 95 表示 95%；身法修正填 0.5 表示双方每相差 1 点身法，命中率变化 0.5 个百分点。点「新增一级」会复制当前最高等级的数值，新行可以单独修改。顶部「保存」同时保存技能图与绑定的等级表。若多个技能引用同一张表，保存的改动对这些技能都生效。
  4. 单段填写 100。三段时选「执行多次」，次数 3，点「按当前 3 段均分 100%」生成三栏，再分别填 20、30、50。段数与占比数量必须一致，合计 100%。每段只处理自己的份额，落空的份额直接结束。
  5. 在公式结算动作里选「公式试算等级」，再点「看公式」，即可使用这一级的表行试算，并调整模拟属性。Preview 的「试放技能等级」单独选择。用「用原生节点树编辑连线」改公式；若只想改这一招，先在该槽点「专用副本」。改了输出节点时，在公式页选新节点，再点「把当前节点设为运行时输出」并保存。
施放：最终攻击 × 等级倍率 + 固定项→抵达：本段独立判命中→成功：分段伤害减去本段分摊的实时防御→易伤、护盾、剩余生命

例如总伤害 200，三段占 20%、30%、50%，各分得 40、60、100。若目标当前防御 50，三段均命中且没有护盾或易伤，则实际扣 30、45、75。第二段落空时它扣 0，第三段仍只占原定的 50%。防御在段与段之间改变时，后续命中使用新值。

跟做一次复制、修改和复测

  1. 在编辑模式选「星弧连闪」，点复制技能。选自己的目录，命名为 星弧连闪_测试.asset。工作台会切换到副本。
  2. 选「分段命中与公式结算」行，记下原间隔 0.14 秒，在副本中改为 0.30 秒。保留执行次数 3 和原有的公式引用、段占比。按 Enter 并点保存。
  3. 切去另一张图，再重新选择副本，核对间隔与次数。打开节点图可以看到，三次结算来自同一行动作。
  4. 以 8 米试放，观察第一段到第三段的时间跨度是否从约 0.28 秒变成 0.60 秒。如果接下来要同时改整招的威力和分段权重，按飞剑公式接线步骤制作。
  5. 要改成两段，修改执行次数，再调整两个占比并使合计为 100%。要拉开节奏，修改执行间隔。要延后整招的出剑时间，修改开始时间。三者对应不同的可见结果。

要增加表现，可把时间游标移到所需时刻，点添加动作 → 施法提示，选择作用实体、填写事件名和时长。移除动作时先选中该时间轴行，点移除当前动作。工作台支持团结编辑器的撤销操作。

试放自己指定的角色、执行器或武器

  1. 在 Preview → 当前场景试放 拖入一个 CombatDamage，或用查找使用此图的场景组件。空场景可点创建场景测试组件，它会绑定当前图并关闭自动物理检测。
  2. 在同窗展开命中检测、投射物与动态变量检查原组件设置。在「试放对象」里把带有效 EntityComponent 的施加者和目标拖到对应槽里。
  3. 进入 Play。确认执行组件使用当前这张图并完成初始化，然后点试放当前技能。手动试放通过指定目标调用图。要测试碰撞层、射线或实际命中体，请另用武器或角色的正常施法入口触发物理检测。

MCC 原版多个延迟动作复用同一个执行器时可能串目标。快速试放为每次施放分配独立实例。接入正式角色时，并行施放也应保留独立的执行上下文和足够的存活时间。

验证护盾、易伤和未命中

  • 护盾吸收。让主角先施放「清罡护体」，待护盾生效，让怪物施放「雷鳞震翅」。检查本段是否命中，再比较防御后伤害与当前盾量。65 点盾足以吸收本段时，生命维持原值。
  • 回复封顶。记录施放前的当前生命与最大生命。例如生命 80/100，回复 28 后应为 100/100。如果 100/100 时施放，仅凭血条看不出回复，需要另验护盾吸收。
  • 易伤与取整。缚影蚀脉命中先挂易伤，再将防御后伤害乘 1.35，按样例现有规则取整，最后扣盾。把专用命中公式调成 0 可复测落空，目标不应获得该次易伤。
  • 射程失败。先用 8 米观察「御剑穿云」抵达后的判定，再改 20 米。射程在前摇结束时检查，实际角色仍在移动，观察当时的距离。未通过时不会发射飞剑或扣血。

九图使用生命属性 chp 和最大生命 hp。护盾和易伤同时作用于这些技能的命中及 MCC「修改属性 → 减法」对同一属性的伤害。其他游戏系统自行直接写生命时，需要按其伤害入口接入相同规则。

常见问题

技能库找不到某张图

点顶部「技能库」，清空「查找技能」。分组标题下直接列出技能。工程内 Assets/WhiteFog/Skills/ 下的图区分主角和怪物，分组由该图的「默认施放方向」决定。保存在其他目录的副本列在「其他技能图」，列表显示完整资产路径。

点了快速试放，还在等角色

确认活跃场景是 DemoScene，处于 Play，游戏未暂停，主角存活。预览场景会在运行中生成怪物，工作台会等待可交互的双方。若主角死亡，先按场景提示重新开始，再点试放。

能看到特效，但伤害看起来偏少或偏多

先查射程、技能等级表、各段占比、命中率、目标防御与当前生命，再查护盾或易伤，再确认次数、间隔与在途时间。血量不足时结算会受剩余生命限制。预览场景里的敌人会自行攻击；比对单招时应给双方足够生命，观察受术者的变化。

编辑框变灰，或节点图和工作台显示不同

先退出 Play。若节点图正在编辑同一资产，点「切回工作台编辑」。确认正在编辑原图还是副本，用路径核对同名技能。输入框按回车后再保存。

Console 出现找不到 SkillPlayback 或自定义动作

检查 Assets/SoftKitty/MasterCombatCore/Scripts/Core/SkillPlayback.cs、动作脚本及其 _interface.txt 是否已导入。等待脚本编译结束，从 Console 第一条红色错误开始排查。运行时反射类型同时在插件 link.xml 中登记。

如何查看更复杂的条件和公式

选中图后点「打开节点图」，从根节点的触发输入和动作输出追查连线。工作台中显示「来自节点」的端口说明它连接了公式或分支。原图使用方法见团结技能节点编辑器手册。
